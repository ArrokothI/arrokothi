# Coordinator responsibility map

This is a source/design audit of existing behavior at B, not a design for waits, Effects or persistence. Rule owners were reached through `mental-model/reference.md`: submission ordering and atomic decisions in `mechanisms/execution-cycle.md`; separate powers in `mechanisms/authority.md`; scoped identities/receipts in `concepts/identity.md`; retained history in `concepts/state.md` and recovery/evidence mechanisms.

The design should make invalid combinations unrepresentable at module boundaries, not merely add another analysis inventory. Prefer an explicit plan union over a generic patch object that accepts arbitrary callbacks. Preserve exact replay and refusal precedence during refactoring; rejected requests may still append their authorized refusal and must not accidentally become no-ops. A callback may decide first, so plans must be formed or revalidated against the resulting state before apply. Restricting write access is a structural guarantee; correct plan selection remains a semantic claim.

Evidence: `enumeration-occurrences.json` supplies original finding locations; `measurements.json` pins current source hashes. `probes/source-map.py` reproduces the named source-site locations. No type/module decomposition was implemented or benchmarked by this audit.
