1: /**
2:  * K11-R2-EVID-01 - retained evidence is not caller-mutable, on every path that exposes it.
3:  *
4:  * `mental-model/concepts/identity.md` calls a receipt "retained evidence that one specific request
5:  * was accepted", K1.1-C1/C6 require an exact replay to return *the original* decision and token, and
6:  * K1.1-C9 reports recorded refusals through inspection. The Kernel deliberately hands the caller the
7:  * same object it retains, so those claims hold only if the object cannot be edited.
8:  *
9:  * The failure these cases exist against is narrow and entirely ordinary: `readonly` in TypeScript is
10:  * erased at run time, so a caller can cast it away and assign. Before this correction, doing that to
11:  * a returned receipt edited the Kernel's retained decision, and the Kernel's own later replay and
12:  * inspection reported the forged value as what it had accepted.
13:  *
14:  * Every case therefore does three things: take the evidence through one exposed path, attempt an
15:  * ordinary mutation with `readonly` cast away, then ask the Kernel again and check the answer is the
16:  * original. A frozen object throws on assignment under the module's strict mode, so the attempt is
17:  * wrapped rather than asserted to throw: what is under test is that the Kernel's retained answer is
18:  * unchanged, not which of the two ways the assignment failed.
19:  */
