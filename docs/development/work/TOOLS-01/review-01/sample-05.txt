74: ## 4. Exact permitted value that makes the absolute requirement impossible
75:
76: ```ts
77: const hostile: Promise<void> = Promise.reject(new Error("own ctor reject"));
78: Object.defineProperty(hostile, "constructor", {
79:   get(): never { throw new Error("own ctor boom"); },
80:   configurable: false, // unsanitizable: delete/redefine throws before any handler exists
81: });
82: // Driver returns `hostile` from `deliver` (already rejected at return).
83: ```
84:
85: This is a native `Promise` (from `Promise.reject`), hence a `Promise<void>` admitted by the
86: declared `void | Promise<void>` boundary. It carries no subclass, no Proxy, and no ambient
87: pollution; the hostile slot is own, non-configurable, and throwing.
88:
89: Every legal in-process observation throws before a rejection continuation exists:
90:
91: - `Promise.prototype.then.call(hostile, …)` → `SpeciesConstructor` does
92:   `Get(hostile,"constructor")` → throws `own ctor boom` before `PerformPromiseThen`.
93: - `hostile.catch(…)` / `finally` → same `then` path, same synchronous throw.
94: - `Promise.resolve(hostile)` → `Get(hostile,"constructor")` throws before any
95:   same-constructor fast path or capability assimilation.
96: - `await hostile` → `PromiseResolve(%Promise%, hostile)` → same `Get` throw; the `await`
97:   itself does not throw synchronously but the assimilation job rejects with the attach
98:   error while the original `own ctor reject` remains unhandled.
99: - `Promise.all([hostile])` / `race` / `allSettled` / `any` → same `Get`/`then` assimilation,
100:   same pre-handler throw.
101:
102: Observed locally under `--unhandled-rejections=strict`: `direct then threw sync: own ctor
103: boom`, `catch threw sync: own ctor boom`, `resolve+then threw sync: own ctor boom`,
104: followed by strict crash on the original `own ctor reject` (exit 1). Prototype swap does not
105: help because the own slot shadows the prototype. `delete`/`defineProperty` sanitization
106: throws (`TypeError`, non-configurable) before any handler exists. A second variant with the
107: same consequence is a subclass with non-configurable throwing static `Symbol.species` plus a
108: non-extensible instance (`Object.preventExtensions` defeats the prototype-swap bypass).
109:
110: No JS mechanism adds a reaction without `SpeciesConstructor`; `process.on('unhandledRejection')`
111: does not prevent the strict crash (verified: handler installed yet exit 1). The escape is
112: therefore not an implementation gap but a property of the value combined with the spec.
